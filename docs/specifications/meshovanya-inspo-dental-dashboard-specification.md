**Inspo Dental — Dashboard Specification**

Four-Layer Reporting System: Metrics, Sources & Visuals

Prepared by Roman Siladii

May 2026

**About this document**

This document specifies every metric across the four-layer dashboard system being built for Inspo Dental. Layer 1 (daily) is for Brooke at the front desk. Layer 2 (weekly) is the operator diagnostic for Roman and Matt. Layer 3 (bi-weekly) is the executive view for Mike. Layer 4 (monthly) is the financial and strategic review.

Every metric below includes seven attributes: a stable reference number, the metric name, the meaning or exact formula, the data source, an illustrative example value, the industry benchmark with the source where available, and a brief description of how the metric should be displayed visually on the dashboard.

*Industry benchmarks are sourced from published 2024–2026 data: ADA, Levin Group, Pearl AI, ConvertLens, Dentplicity, BoomCloud, Dandy, Dentistry IQ, Jarvis Analytics, Dental Economics, ConvertLens, Mailchimp healthcare benchmarks, Twilio \+ Klaviyo SMS standards, Velocify/Kixie/InfluxMD speed-to-lead research, WordStream, 2POINT Agency, OwlClaw, and dental-specific case studies (Modern Dentistry, mConsent/Crescent Family Dental, Marketly, DataFlux, DentalBase, Postmarkr).*

Total metric count: 123 metrics across 4 layers (20 \+ 43 \+ 22 \+ 38). Narrative-only zones (such as the 3-Wins / 3-Losses / 3-Next blocks and the Strategic Decisions sections) are not metrics and are noted in each layer’s introduction rather than tabled.

**Layer 1 — Daily Operational Dashboard**

*Audience: Brooke (front desk). Cadence: real-time / daily. Surface: GHL mobile \+ simple HTML view.*

Layer 1 is an action queue, not an analytics dashboard. Every metric must answer the question “what do I do next?” within the next 30 minutes. Mobile-first design. Time-sensitive items (inbound replies) sit at the top; gamification (receptionist score) sits lower. The dashboard has 5 zones plus a footer reactivation strip; this table lists all 20 metrics across those zones.

*Audience: Roman \+ Matt. Cadence: weekly. Surface: custom HTML on GitHub Pages, Looker Studio, or Databox.*

Layer 2 is diagnostic. It answers “is the system working, where is it leaking, and what should we change next week?”. Desktop-first with WoW comparisons on every metric. Funnel-first thinking: the middle zones make leakage points visible at a glance. Includes 8 zones spanning 43 metrics. Zone 8 (Experiments & Next Week) is a structured-text zone, not metric-based, and is described in the layer documentation rather than tabled here.

**Visual Vocabulary — quick reference**

Across the four layers the visual treatments fall into a small set of reusable patterns. This is the working vocabulary referenced in the “Visual Treatment” column above.

• Number card: single big number with an optional traffic-light dot, comparison delta, and small footnote (e.g., “Updated 3 days ago”). Used for any single-value KPI.

• Sparkline: small inline line chart (typically 12 data points) showing trend without axis labels. Used for trend-direction reads.

• Progress bar: horizontal bar filling from left to right, color-shifting at thresholds. Used for goal-tracking metrics.

• Funnel chart: horizontal stages with conversion % between each stage. Used for the lead-to-attended-to-treatment funnel.

• Heatmap grid: small 2D matrix (e.g., tracks × touches), color intensity \= metric value. Used for reply-rate-by-touch and time-in-stage views.

• Donut / pie: split visualization of categorical mix (e.g., channel attribution, opt-in source). Used when proportion matters more than absolute count.

• Stacked bar: cumulative comparison across categories (e.g., spend by channel, new patients by source). Used when totals AND splits matter.

• Cohort-line chart: multi-line chart with one line per cohort, showing retention over time. Used exclusively in Layer 4 for cohort retention curves.

• Gauge: arc visualization with color zones (green/yellow/red). Used for utilization, ratios, and bounded-percent metrics.

• Live timer: count-up timer with traffic-light coloring. Used only on Layer 1 for real-time response-time alerting.

• 5-star widget: visual rating display with filled stars; used in Layer 3 reputation zone.

• Narrative block: structured text with bullets for wins/losses/next; not a chart but a UI block requiring its own component.

**Notes on data freshness**

Because Meta ad data comes via PDF/screenshot from a third-party agency, every Meta-derived metric in Layers 2–4 must display a “Updated \[N\] days ago” timestamp. Stale-data thresholds: green if \<2 days, yellow 2–7 days, red \>7 days (the metric card should grey out and show a warning). All other data sources (GHL, Dentrix, Weave, GBP, GA4) refresh nightly via Make scenarios and don’t need per-card freshness indicators unless an automation fails.
